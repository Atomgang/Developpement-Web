# FlexTrainning

Un outil interactif pour apprendre **Flexbox** visuellement en français.

## À propos

FlexTrainning est un projet éducatif conçu pour aider les développeurs web à comprendre et maîtriser les propriétés de disposition Flexbox à travers des exemples interactifs et des démonstrations visuelles.

## Fonctionnalités

- 📚 **Explication des concepts** : Introduction aux axes principal et secondaire de Flexbox
- 🎮 **Mode interactif** : Testez les propriétés d'alignement en temps réel
- 📦 **Exemples pratiques** :
  - Conteneur flexible de base
  - Propriétés `justify-content` et ses variations
  - Propriétés `align-items` et `align-content`
  - Gestion du wrapping avec `flex-wrap`
- 💡 **Retour visuel** : Affichage du CSS appliqué pour chaque manipulation

## Fichiers du projet

- **flexbox-test.html** : Page HTML principale avec structure et exemples
- **flex_styles.css** : Styles et mise en page de l'application
- **flexbox-controls.js** : Logique interactive pour tester les propriétés Flexbox

## Installation

Aucune dépendance externe requise. Clonez le projet et ouvrez `flexbox-test.html` dans votre navigateur.

```bash
git clone <repo_url>
cd FlexTrainning
# Ouvrir flexbox-test.html dans votre navigateur
```

## Utilisation

1. Consultez l'introduction sur les concepts de Flexbox
2. Accédez à la section **Interaction | Tester l'alignement**
3. Sélectionnez une propriété CSS
4. Choisissez une valeur
5. Cliquez sur **Appliquer** pour voir le changement
6. Observez le code CSS généré

## Contenu pédagogique

- **Base** : Comportement par défaut d'un conteneur flexible
- **Justify-content** : Espacement horizontal des éléments
- **Align-items** : Alignement vertical des éléments
- **Flex-wrap** : Gestion du retour à la ligne
